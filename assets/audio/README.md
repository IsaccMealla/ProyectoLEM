# Audios de las cinco escenas

La experiencia reproduce directamente los archivos de narración oficial en formato MP3 para cada una de las 5 escenas:

1. `escena1.mp3` — [ESCENA 1] El Despertar de Franz Tamayo (1879 — 1956)
2. `escena2.mp3` — [ESCENA 2] El Pensamiento y la Educación (1910)
3. `escena3.mp3` — [ESCENA 3] El Nacimiento de UNIFRANZ (1990 — 1993)
4. `escena4.mp3` — [ESCENA 4] Una Universidad en Crecimiento (Presencia Nacional)
5. `escena5.mp3` — [ESCENA 5] El Legado Continúa (Hoy y Mañana)

Cada archivo de audio se sincroniza con el cuadro de diálogo y la animación del pedestal y figura 3D de Franz Tamayo en realidad aumentada.
